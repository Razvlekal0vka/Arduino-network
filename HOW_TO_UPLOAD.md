# 📤 Как загрузить код на Arduino

## 🎯 Вариант 1: Простой код (рекомендуется для начала)

Используйте файл: **`ARDUINO_W5500_SERVER.ino`**

### Шаги:

1. **Установите библиотеку Ethernet2**
   - Откройте Arduino IDE
   - Инструменты → Управление библиотеками
   - Найдите "Ethernet2" и установите

2. **Настройте IP адрес**
   - Откройте файл `ARDUINO_W5500_SERVER.ino`
   - Найдите строку: `IPAddress ip(192, 168, 1, 140);`
   - Измените на ваш IP адрес (например, `192, 168, 1, 100`)

3. **Выберите плату и порт**
   - Инструменты → Плата → Arduino Uno
   - Инструменты → Порт → выберите COM порт вашего Arduino

4. **Загрузите код**
   - Нажмите кнопку "Загрузить" (Upload)
   - Дождитесь завершения загрузки

5. **Проверьте работу**
   - Откройте Serial Monitor (9600 baud)
   - Должно появиться:
     ```
     === Arduino W5500 Server ===
     Initializing Ethernet...
     Server IP: 192.168.1.140
     Server started on port 80
     Ready!
     ```

6. **Проверьте в браузере**
   - Откройте браузер
   - Перейдите по адресу: `http://192.168.1.140`
   - Должна открыться веб-страница с данными

## 🚀 Вариант 2: Продвинутый код (с неблокирующими таймерами)

Используйте файлы из папки: **`Arduino_with_network/`**

### Требования:
- PlatformIO (или Arduino IDE с копированием файлов)

### Если используете Arduino IDE:

1. **Скопируйте файлы:**
   - `Arduino_with_network/src/main.cpp` → переименуйте в `main.ino`
   - `Arduino_with_network/src/NonBlockingTimer.h` → оставьте как есть

2. **Создайте папку проекта:**
   ```
   MyArduinoProject/
   ├── main.ino
   └── NonBlockingTimer.h
   ```

3. **В main.ino добавьте в начало:**
   ```cpp
   #include "NonBlockingTimer.h"
   ```

4. **Установите библиотеку Ethernet2** (как в варианте 1)

5. **Настройте IP адрес** (как в варианте 1)

6. **Загрузите код**

---

## 🔧 Настройка IP адреса

### Вариант A: Статический IP (рекомендуется)

В коде найдите строку:
```cpp
IPAddress ip(192, 168, 1, 140);
```

Измените на ваш IP:
```cpp
IPAddress ip(192, 168, 1, 100);  // Ваш IP
```

### Вариант B: DHCP (автоматический)

Код автоматически пытается получить IP через DHCP. Если не получается, использует статический IP.

## 📋 Что делать если не работает?

### 1. Проверьте подключение
- Убедитесь, что все пины подключены правильно
- Проверьте питание (VCC и GND)
- Проверьте Ethernet кабель

### 2. Проверьте Serial Monitor
- Откройте Serial Monitor (9600 baud)
- Должно появиться сообщение с IP адресом
- Если видите "DHCP failed" - это нормально, используется статический IP

### 3. Проверьте IP адрес
- Убедитесь, что IP адрес в коде соответствует вашей сети
- Например, если ваш роутер на `192.168.1.1`, то Arduino должен быть на `192.168.1.XXX`

### 4. Проверьте библиотеку
- Убедитесь, что установлена библиотека **Ethernet2** (не Ethernet!)
- Для W5500 нужна именно Ethernet2

### 5. Проверьте в браузере
- Откройте `http://ВАШ_IP` (например, `http://192.168.1.140`)
- Должна открыться веб-страница
