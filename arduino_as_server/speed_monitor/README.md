# Arduino Speed Monitor

Система для мониторинга скорости передачи данных между Arduino сервером и Python клиентом с графиками в реальном времени.

## 📁 Структура файлов

```
speed_monitor/
├── arduino_speed_server.cpp    # Arduino сервер для стресс-тестирования
├── python_speed_client.py      # Python клиент с графиками в реальном времени
├── simple_speed_test.py        # Упрощенный клиент для быстрого тестирования
└── README.md                   # Этот файл
```

## 🚀 Быстрый старт

### 1. Загрузка кода на Arduino

1. Откройте `arduino_speed_server.cpp` в Arduino IDE
2. Убедитесь, что выбрана правильная плата и порт
3. Загрузите код на Arduino
4. Откройте Serial Monitor (9600 baud) для просмотра логов

### 2. Установка зависимостей Python

```bash
pip install requests matplotlib numpy
```

### 3. Запуск тестирования

#### Вариант 1: Упрощенный тест (рекомендуется для начала)

```bash
cd arduino_as_server/speed_monitor
python3 simple_speed_test.py
```

#### Вариант 2: Полный тест с графиками

```bash
cd arduino_as_server/speed_monitor
python3 python_speed_client.py
```

## 📊 Возможности системы

### Arduino сервер (`arduino_speed_server.cpp`)

- **Статистика производительности**: подсчет запросов, байт, времени ответа
- **Различные endpoints**:
  - `/api/status` - статус системы (быстрый)
  - `/api/sensors` - данные датчиков (средний)
  - `/api/stress` - стресс-тест с большими данными (медленный)
  - `/api/stats` - статистика производительности
  - `/api/control` - управление системой

### Python клиенты

#### Простой клиент (`simple_speed_test.py`)
- Тестирование отдельных endpoints
- Стресс-тест с случайными запросами
- Детальная статистика (время ответа, скорость, процентили)
- Не требует matplotlib

#### Полный клиент (`python_speed_client.py`)
- Графики в реальном времени
- 4 графика одновременно:
  - Время ответа (мс)
  - Скорость передачи (байт/сек)
  - Запросов в секунду
  - Объем данных (накопленный)
- Различные режимы тестирования

## 🎯 Режимы тестирования

### 1. Status (статус)
- **Частота**: 10 запросов/сек
- **Размер данных**: ~150 байт
- **Назначение**: Тест быстрых запросов

### 2. Sensors (датчики)
- **Частота**: 5 запросов/сек
- **Размер данных**: ~120 байт
- **Назначение**: Тест средних запросов

### 3. Stress (стресс-тест)
- **Частота**: 1 запрос/сек
- **Размер данных**: ~2500 байт
- **Назначение**: Тест больших объемов данных

### 4. Mixed (смешанный)
- **Частота**: 2 запроса/сек
- **Размер данных**: переменный
- **Назначение**: Реалистичный тест

## 📈 Метрики измерения

### Время ответа
- Среднее время ответа (мс)
- Медиана времени ответа
- Минимальное/максимальное время
- Процентили (50%, 90%, 95%, 99%)

### Скорость передачи
- Запросов в секунду
- Байт в секунду
- Кбит в секунду
- Общий объем данных

### Надежность
- Процент успешных запросов
- Количество ошибок
- Стабильность соединения

## 🔧 Настройка

### Изменение IP адреса

В Arduino коде:
```cpp
IPAddress ip(192, 168, 1, 140);  // Измените на ваш IP
```

В Python коде:
```python
client = ArduinoSpeedClient("192.168.1.140")  # Измените на IP Arduino
```

### Настройка частоты тестирования

В `python_speed_client.py`:
```python
self.test_intervals = {
    "status": 0.1,    # 10 запросов в секунду
    "sensors": 0.2,   # 5 запросов в секунду
    "stress": 1.0,    # 1 запрос в секунду
    "mixed": 0.5      # 2 запроса в секунду
}
```

## 📊 Интерпретация результатов

### Хорошие показатели
- Время ответа: < 100 мс
- Скорость: > 1000 байт/сек
- Процент успеха: > 95%

### Средние показатели
- Время ответа: 100-500 мс
- Скорость: 100-1000 байт/сек
- Процент успеха: 80-95%

### Плохие показатели
- Время ответа: > 500 мс
- Скорость: < 100 байт/сек
- Процент успеха: < 80%

## 🐛 Устранение неполадок

### Arduino не отвечает
1. Проверьте IP адрес
2. Убедитесь, что Ethernet подключен
3. Проверьте Serial Monitor для ошибок
4. Перезагрузите Arduino

### Ошибки Python
1. Установите зависимости: `pip install requests matplotlib numpy`
2. Проверьте подключение к сети
3. Убедитесь, что Arduino сервер работает

### Медленная работа
1. Уменьшите частоту запросов
2. Проверьте качество Ethernet соединения
3. Закройте другие программы, использующие сеть

## 🔄 Формула расчета скорости

```
Скорость = (Количество символов × Частота обращений) / Время

Пример:
- 50 символов каждые 2 секунды
- Скорость = 50 / 2 = 25 байт/сек
```
