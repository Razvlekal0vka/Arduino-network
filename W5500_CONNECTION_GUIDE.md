# 🔌 Руководство по подключению W5500 к Arduino Uno

## 📋 Анализ ваших пинов

У вас на плате есть следующие пины:
- **GND** - Общий провод (обязательно)
- **VCC** - Питание (обязательно)
- **WCS** - Chip Select (обязательно)
- **MISO** - SPI данные (обязательно)
- **SCK** - SPI тактирование (обязательно)
- **MOSI** - SPI данные (обязательно)
- **RESER** - Reset (желательно, но можно оставить неподключенным)
- **WRST** - Watchdog Reset (НЕ обязателен)

## ✅ Обязательные подключения

### 1. Питание
```
Ваша плата          Arduino Uno
─────────────────────────────────
VCC                 → 5V (или 3.3V, если модуль на 3.3V)
GND                 → GND
```

**⚠️ ВАЖНО**: Проверьте документацию вашей платы! W5500 работает от 3.3V, но многие модули имеют встроенный стабилизатор и могут питаться от 5V.

### 2. SPI интерфейс (обязательно)
```
Ваша плата          Arduino Uno
─────────────────────────────────
MOSI                → Пин 11 (SPI MOSI)
MISO                → Пин 12 (SPI MISO)
SCK                 → Пин 13 (SPI SCK)
```

**Эти пины фиксированы на Arduino Uno и не могут быть изменены!**

### 3. Управляющие сигналы
```
Ваша плата          Arduino Uno
─────────────────────────────────
WCS                 → Пин 10 (Chip Select)
```

**Пин 10 - это стандартный CS пин для Ethernet2 библиотеки**

## 🔧 Желательные подключения

### Reset (рекомендуется)
```
Ваша плата          Arduino Uno
─────────────────────────────────
RESER               → Пин 9 (Reset)
```

**Пин 9 - это стандартный Reset пин для Ethernet2 библиотеки**

## ❌ Необязательные подключения

### WRST (Watchdog Reset)
```
WRST                → НЕ ПОДКЛЮЧАТЬ (можно оставить свободным)
```

Этот пин используется для сброса по watchdog таймеру и не обязателен для базовой работы.

## 📊 Полная схема подключения

```
┌─────────────────┐         ┌──────────────────┐
│   Ваша плата    │         │   Arduino Uno     │
│     W5500       │         │                  │
├─────────────────┤         ├──────────────────┤
│ VCC             │─────────→│ 5V (или 3.3V)    │
│ GND             │─────────→│ GND              │
│                 │         │                  │
│ MOSI            │─────────→│ Пин 11 (MOSI)   │
│ MISO            │─────────→│ Пин 12 (MISO)   │
│ SCK             │─────────→│ Пин 13 (SCK)    │
│                 │         │                  │
│ WCS             │─────────→│ Пин 10 (CS)     │
│ RESER           │─────────→│ Пин 9 (Reset)    │
│                 │         │                  │
│ WRST            │         │ (не подключать) │
└─────────────────┘         └──────────────────┘
```

## 🔍 Проверка в коде

В вашем коде используется библиотека `Ethernet2`, которая по умолчанию использует:
- **CS (Chip Select)**: Пин 10
- **Reset**: Пин 9

Если вы хотите использовать другие пины, нужно указать их явно:

```cpp
#include <SPI.h>
#include <Ethernet2.h>

// Если нужно изменить пины (по умолчанию CS=10, RST=9)
// Ethernet2(uint8_t csPin = 10, uint8_t rstPin = 9);

byte mac[] = { 0xDE, 0xAD, 0xBE, 0xEF, 0xFE, 0xED };
IPAddress ip(192, 168, 1, 140);
EthernetServer server(80);

void setup() {
  Serial.begin(9600);
  
  // Инициализация Ethernet (использует пины 10 и 9 по умолчанию)
  if (Ethernet.begin(mac) == 0) {
    Serial.println(F("DHCP failed, using static IP"));
    Ethernet.begin(mac, ip);
  }
  
  server.begin();
  Serial.print(F("Server IP: "));
  Serial.println(Ethernet.localIP());
}
```

## ⚠️ Важные замечания

1. **Напряжение питания**: 
   - W5500 работает от 3.3V
   - Если на вашей плате есть стабилизатор, можно подавать 5V
   - Если нет стабилизатора, используйте 3.3V (но ток может быть недостаточным)

2. **SPI пины фиксированы**:
   - MOSI, MISO, SCK нельзя менять на Arduino Uno
   - Это аппаратные пины SPI

3. **CS пин можно изменить**:
   - По умолчанию используется пин 10
   - Можно использовать другой пин, но нужно указать в коде

4. **Reset пин**:
   - Рекомендуется подключить для надежной работы
   - Можно оставить неподключенным, если модуль имеет внутренний reset

5. **WRST (Watchdog Reset)**:
   - Не обязателен для базовой работы
   - Используется только для продвинутых функций

## 🧪 Проверка подключения

После подключения загрузите код и проверьте Serial Monitor:

```
=== Arduino Speed Test Server ===
Initializing Ethernet...
Server IP: 192.168.1.140
```

Если видите IP адрес - подключение работает правильно!

## 🎯 Минимальное подключение (если RESER не подключен)

Если вы не подключите RESER, модуль все равно должен работать, но может быть менее стабильным:
- VCC → 5V
- GND → GND
- MOSI → Пин 11
- MISO → Пин 12
- SCK → Пин 13
- WCS → Пин 10

**WRST можно не подключать вообще!**
